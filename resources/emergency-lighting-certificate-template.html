What is an emergency lighting certificate?

It is the site record that an existing emergency lighting installation still meets BS 5266. Facilities managers and insurers often want it alongside visit reports and the logbook — it covers the building, not a single test.

Don’t use it for brand-new work, alterations, or to check an undocumented older system against a newer edition of the code. Those need a different certificate.

When do you need one?

  • After a periodic inspection — when you are signing off the installation as a whole
  • Client handover — a formal record for the person responsible for the building
  • Several sites — the same certificate format everywhere you work
  • With visit reports — the certificate is for the building; visit reports are for each test

How to fill it in

  1. Download the PDF and pull the site details from the logbook.
  2. Fill in the client, the building, and your company.
  3. Work through the results table — tick, cross, or N/A for each check.
  4. Note anything that doesn’t match the code, and any test instruments used.
  5. Sign it and give it to the person responsible for the building.

Visit report or certificate?

You may need both. A visit report is what you leave after a monthly or annual test. This certificate is the record for the building — often updated when you finish the annual inspection, and kept with the visit reports and logbook.

Mistakes that undermine a certificate

A blank PDF only works if you fill every part. These are the gaps clients and insurers notice first.

  • Using it for a new installation

    This form is for an existing installation. Brand-new work needs a completion certificate, not this periodic one.

  • Leaving results rows blank

    Tick, cross, or N/A every check you actually did. Empty rows look unfinished.

  • No next inspection date

    The person responsible for the building needs a clear date to work from. Insurers notice if it’s missing.

  • No signature

    A certificate without a dated signature isn’t a valid record. A blank template won’t remind you.

Frequently asked questions

Is this for new installations?

No. Use this for an existing installation. Brand-new work, alterations, or checking an old system against a newer code edition need a different certificate.

What is on the results table?

Page 2 lists the periodic checks from BS 5266. For each one, mark tick, cross, or N/A based on what you actually inspected.

How is this different from a visit report?

This certificate is for the building. The visit report is what you hand over after a single test. See visit report vs certificate vs logbook for the full split.

How many pages is it?

Four pages: client and building, your declaration, inspection results, and notes for the person receiving it.
