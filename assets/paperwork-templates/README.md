# Paperwork templates (marketing downloads)

Blank PDF templates generated from the **real** Beacon builders in `monolith-beacon`
(`blankTemplate: true`). Same layout as issued paperwork; empty fields for manual completion.

## Regenerate

```bash
cd ../monolith-beacon
npm run generate:marketing-samples
```

## Notes

- Same layout as issued Beacon paperwork; empty fields for manual completion.
- Source: `app/js/dev/marketing-sample-export.js` + `scripts/generate-marketing-samples.mjs`.
