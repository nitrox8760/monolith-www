FAQ

Questions before you try it.

Does Beacon work offline on site?

Yes. Field is a PWA built for plant rooms and basements. Record tests offline; sync when you’re back online. Console is for office use when connected.

Is this enough for BS 5266?

Beacon is BS 5266-aware: monthly and annual programmes, asset register, defects, visit PIR, and periodic certificate. It helps you record and issue supporting paperwork — duty-holders stay responsible for compliance. It is not a BSI product certification.

What’s the difference between Field and Console?

Field is the phone/tablet app for the visit — testing, defects, and history offline. Console is the desktop workspace for sites, team, audit, and certificates across the organisation. One login family, one sync backend.

Can I import an existing logbook?

Yes. Create a site and import fittings from a spreadsheet, then set switches, Site IDs, and tracking before you run the first test.

Do I need an App Store download?

No. Beacon Field installs as a progressive web app from the browser on phone or tablet. Console runs in the desktop browser. No card required to start the open beta.

What can I issue today?

From a completed visit you can issue a fitting test report and a visit PIR. For the site you can issue a periodic inspection and testing certificate. Issued documents are immutable once locked.

How much does Beacon cost?

Free during open beta. We’ll announce pricing before anything is charged — no surprise lock-in.

Where is my data stored?

Organisation data syncs to Beacon cloud (Supabase). Field can keep visit work offline on the device until you sync. See the privacy page for details.
